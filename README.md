# UU 经营报告

铜陵UU台球俱乐部经营报告工具：选择周期（日报 / 周报 / 季报 / 半年报 / 年报），填入或导入商云宝数据，自动生成营收报告。

## 功能

- **周期报告**：日 / 周 / 季 / 半年 / 年，填数据即出报告，环比上期、目标达成自动计算
- **资金口径营收**：当日营收 = 现金 + 农商卡到账 − 现金存入 + 团购核销（未提现）；商云宝数据作为参考核对
- **商云宝导入**：支持经营报表、综合报表、商品综合报表、第三方平台报表、会员卡变动记录、礼金卡变动记录（日维度与周维度均可）
- **商品与毛利**：导入商品综合报表后自动计算销售额、成本、总利润、毛利率
- **会员**：储值卡 / 礼金卡消费，新老会员充值分开统计
- **团购**：核销与退款分开统计，营收按净额（核销 − 退款）计入
- **导出**：PDF、Word、Excel、长图、微信文案

## 开发

```bash
npm install
npm run dev          # http://localhost:3000
npm test             # 单元与导入回归测试
npm run build        # 产出 dist/
```

## 打包桌面 exe

```bash
npm run build
pyinstaller UU经营报告.spec
```

## 数据

数据保存在 exe 旁的「数据」文件夹（可通过 exe 旁 `配置.json` 指定共享目录），无需联网，自动备份。
